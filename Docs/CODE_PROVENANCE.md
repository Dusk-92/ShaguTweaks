## Modified and added material

The fork contains additional or modified configuration and modules for
Turtle WoW / OctoWoW compatibility and other quality-of-life features.

Those changes are maintained independently by this fork. Historical Git commits
remain the authoritative record for individual modifications.

## Reference-only credits

The README credits pfUI and zUI as sources of ideas/reference. That general
credit is not used as evidence that unspecified source files were copied.

Any future confirmed copied or substantially adapted third-party component
should be recorded file-by-file in `THIRD_PARTY_NOTICES.md`.

## Licensing boundary

A matching upstream Git object proves provenance/file identity, not ownership of
every underlying concept or visual element.

The repository therefore keeps software-license attribution separate from asset
provenance.
